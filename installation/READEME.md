# Chapter 01 - Jenkins Installation

## 📖 Introduction

Before building CI/CD pipelines, the first step is to install Jenkins correctly.

Jenkins can be deployed in several ways depending on the environment and the project requirements. The two most common installation methods are:

* **Native installation (Host)** – Jenkins runs directly on the operating system.
* **Docker installation** – Jenkins runs inside a Docker container.

Both approaches are widely used in the industry and each has its own advantages and disadvantages.

In this chapter, we will explore both methods, explain when to use each one, and provide step-by-step installation guides.
